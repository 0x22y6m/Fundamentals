# Double pointer
```
 int i=5;           //Static Value
 int *ptr1=&i;      // Single pointer
 int **ptr2=&ptr1;  // double pointer
 int ***ptr3=&ptr2; // Triple pointer 
```
 Likewise we can go upto how many we required.
